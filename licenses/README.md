# Bundled license fallback

`@nodable/entities@3.0.0` omits its license file from its published package. `nodable-entities-3.0.0.txt` is copied verbatim from its declared upstream repository, [nodable/val-parsers LICENSE](https://github.com/nodable/val-parsers/blob/main/LICENSE), Git blob `561468f111a66df52cc0f1934642bb9fdd22a212`. The build only uses this fallback for that exact package/version. All other license texts come from installed packages found in bundle metadata.

`@nodable/entities@3.0.0` 发布包遗漏许可证文件，此处按原文保存其声明的上游仓库许可证（Git blob 见上）。构建仅对该精确版本使用此离线副本，其他许可证从构建元数据对应的已安装依赖读取。
