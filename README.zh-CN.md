# EdgeEver 热点追踪

[English](README.md) · [实现原理](docs/architecture.zh-CN.md)

输入关心的话题，了解近期变化，把带来源的研究报告保存为 EdgeEver 笔记。用户无需安装 Last30Days、Python、Docker，也无需额外部署研究服务。

**当前状态：v0.1.0 预览版。** 插件需要新增的 `ai:generate` 和 `research:search` 宿主能力。本仓库包含可复现的 EdgeEver 适配代码，并已在本地联调；**支持这些能力的 EdgeEver 正式版本尚未发布**。旧版宿主会拒绝不支持的权限，单独安装插件不能升级宿主。

## 已实现

- 研究最近 7、30、90 天的动态，提供快速浏览、标准研究、深入研究三种模式。
- 聚合新闻资讯、Hacker News、GitHub 公开 Issue/PR、Reddit 公开订阅源。
- 拆解关键词、去重、筛选相关资料，沿用 EdgeEver 默认 AI 模型生成带引用的报告。
- 基于已有证据追问，一键保存笔记，导出 Markdown 或 HTML。
- 当前设备保留最近 30 次研究和最多 30 个追踪话题，比较本轮与上轮取得的不同链接。
- 可选每日 09:00 按设备时区更新，并自动归档到指定笔记本。每日计划默认关闭，仅在桌面端保持运行时执行；错过的任务跳过。

新闻和 Reddit 提供标题／正文片段，不代表已读取文章全文或完整评论。Hacker News 每次查询为前两条结果各补充最多三条评论。GitHub 提供 Issue/PR 正文及评论数，当前不抓取评论正文。来源失败或受限会明确展示。

首版尚不包含 X、YouTube、TikTok、Instagram、无需输入主题的热点发现、全天候后台抓取，也不将检索结果数量当作全网趋势。引用只能确认来源链接确实取得，不能自动证明生成内容正确，重要结论仍应核对原文。

## 在支持研究接口的 EdgeEver 中安装

1. 如需 AI 报告，先在「个人中心 → AI 设置」选择默认模型。已配置用户无需重复填写密钥。
2. 打开「插件市场」，粘贴下面的仓库地址，安装并启用。
3. 在命令面板打开「热点追踪：开始研究」，输入主题。

```text
https://github.com/tianma-if/edgeever-hotspot-tracker
```

未配置 AI 时仍可检索公开资料，界面会明确说明当前不是 AI 综合报告。模型调用按用户选择的供应商计费；来源无需新增 API 密钥，但可用性受实例网络和来源限流影响。

插件运行在 EdgeEver 的可信客户端插件环境中，并非强隔离 JavaScript 沙箱。本插件通过有权限检查的宿主接口调用能力，不读取浏览器 Cookie，也不接收 AI 供应商密钥。检索关键词经已有 EdgeEver 后端发送至公开来源；问题和资料摘要发送给已配置的 AI 供应商。研究历史、追踪列表保存在当前设备；主动保存的笔记按工作区原有机制同步。

## 开发

需要 Bun 1.3.14 或更新版本。以下是开发者命令，普通用户无需运行。

```sh
bun install --frozen-lockfile
bun run check
bun run test:live  # 可选：真实查询四个公开来源，不调用 AI
bun run dev        # 127.0.0.1:4178 上的插件静态开发包服务
```

在适配后的 EdgeEver 本地开发实例中安装 `http://127.0.0.1:4178/manifest.json`。该开发服务仅提供插件文件，不承担研究业务。修改代码后重新构建、重新安装开发清单以更新缓存包，再刷新 EdgeEver 页面。

构建输出 `dist/main.js` 单文件浏览器模块、`manifest.json`、`LICENSE` 和 `THIRD_PARTY_NOTICES.txt`。通过 GitHub Release 分发；仓库根目录的清单必须与对应 Release 的清单完全一致。标签构建默认发布为预览版；CI 只运行确定性测试和构建，不调用公开来源或 AI。

## EdgeEver 维护者适配

参见[适配指南](integration/README.zh-CN.md)。适配包括现有共享后端的固定来源搜索、已有模型生成接口、SDK、客户端与插件宿主，也修复了插件面板延迟挂载导致的空白问题。这些改动应随 EdgeEver 正常发版交付，不应让插件用户另行部署。

适配脚本只更新指定锚点及所属适配文件，但不提供事务回滚，请在可以审阅变更的源码目录运行。它不会提交、部署、迁移数据库或修改已保存的密钥。

采用与 EdgeEver 一致的 AGPL-3.0-or-later。实现借鉴 Last30Days 的多来源研究思路，使用独立 TypeScript 代码，不打包或调用 Last30Days。依赖说明见[第三方声明](THIRD_PARTY_NOTICES.md)。
